🌐 Personal Portfolio Website
Aabhas Tripathi – UI/UX Designer | Data Analyst | Developer

This repository contains the source code for my personal portfolio website, built to showcase my projects, skills, and professional background. It highlights my expertise across UI/UX Design, Data Analytics, and Full-stack Development.

🚀 Features
✅ Modern & Responsive UI

Built with Tailwind CSS for a sleek, mobile-friendly design with smooth layouts.

✅ Custom Components

Reusable <custom-navbar> and <custom-footer> web components for clean code separation.

✅ Project Showcase Section

A grid layout featuring fully designed project cards with links to each GitHub repo.

✅ Interactive Contact Page

A dedicated contact page featuring:

Clean, structured form

Validation

Backend-ready JSON submission format

Social link buttons (LinkedIn, GitHub, Instagram, Email)

✅ Clean Code Organization

index.html – Homepage + Hero + About + Projects

contact.html – Contact form + social links

style.css – Minimal custom styling

script.js – Front-end interactions (form handling, icon rendering)

✅ Feather Icons Integration

Lightweight icon set used throughout the UI.

💻 How to Run Locally

Clone the repository:

git clone https://github.com/aabhastripathy/aabhastripathy.github.io


Open the main file:

index.html


That’s it!
No build process — the website runs directly in the browser.

🔧 Backend (Optional)

The contact form is front-end only, but a backend API route is already assumed:

POST http://localhost:5000/save-contact


You can connect this to Node.js, Express, Firebase, or any backend.
